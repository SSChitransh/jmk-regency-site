# Hotel JMK Regency — website prototype

Responsive, static website concept for Hotel JMK Regency, Ramkatora, Varanasi.

## Files
- `index.html` — website content, SEO metadata, and Hotel structured data
- `styles.css` — responsive layout and visual system
- `script.js` — mobile navigation and WhatsApp booking enquiry flow
- `favicon.svg` — simple text-based favicon

## Preview locally
Open `index.html` in a modern browser. The hotel photos and map are loaded from external websites, so internet access is required for those elements to appear.

## Publish on GitHub Pages
1. Create a repository for the hotel website.
2. Upload the contents of this folder to the repository root (not the parent folder).
3. In **Settings → Pages**, choose the deployment branch and root folder.
4. Publish, then test the site on mobile and desktop.

## Booking behaviour
The form opens WhatsApp with the selected dates, guest count, and room preference addressed to `+91 97936 16550`. It does not store data, accept payments, or confirm bookings. The hotel must reply to confirm availability and booking terms. A backend, booking engine, or form provider is required for an actual automated reservation system.

## Before publishing
- Confirm the current room rates, taxes, meal-plan inclusions, and any cancellation policies.
- Confirm the landline. The hotel website currently lists `0542-4003205`; the brief supplied `0542-400320`.
- Confirm whether wheelchair-accessible facilities are available throughout the property and clarify the specific access arrangements.
- Confirm all transfer services and charges.
- The website refers to typical online standard-room offers around ₹2,300–₹2,600 as indicative only. Public pages have also listed higher room prices, so all displayed pricing language should be checked against current rates.
- Use hotel-owned/licensed photography for permanent use. Images currently link to the hotel's public gallery and should be retained only with permission or suitable rights.

## Design notes
The visual direction uses deep green, warm ivory, and muted brass, with a clear mobile-first booking path, prominent phone contact, location details, room cards, amenities, FAQ, and direct enquiry calls to action.
